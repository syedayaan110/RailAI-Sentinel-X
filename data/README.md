# Data directory

Place only datasets that you are authorised to use and redistribute in this directory.

The primary v5 prototype looks for a labelled CSV named `train delay data.csv` here or in the project root. The expected schema is documented in the root README and the source script.

Large datasets and downloaded archives are excluded by `.gitignore`. Do not commit private, restricted, personal, or unlicensed data. Record the source, licence, collection date, schema, and permitted use before running experiments.

No labelled railway dataset is included in this repository. Synthetic demonstration records are for software testing only and are not evidence of real railway performance.
